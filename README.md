# :sailboat: Ганзейский путь

Одиночная образовательная историческая Narrative Adventure с элементами ролевой игры в сеттинге торгового путешествия по Северо-Западной части Руси и Балтики начала XV века.

## :books: Технологии использованы
* Unity 6
* C#

## Подробное описание

Историю проще понять, когда становишься её участником. В нашей игре игрок сам проходит путь молодого ученика ганзейского купеческого двора, принимает решения, сталкивается с историческими правилами и ограничениями и тем самым изучает особенности торгового путешествия начала XV века. 

<a name="features"></a>

## Особенности проекта
* ***Персонажи и сюжет***: Взаимодействие с историческими героями.
* ***Путешествие***: На различном транспорте по реальным маршрутам.
* ***Торговля***: Мини игры, демонстрирующие особенности торговли.
* ***События***: Квесты по ходу движения по маршруту.
* ***Дипломатия***: Посещение городов, исторических локаций и динамическая система репутации.
* ***Энциклопедия***: Сопровождение игрового процесса фактами из глоссария.
* ***Транспорт***: Интерактивная экскурсия по характерному транспорту эпохи.
